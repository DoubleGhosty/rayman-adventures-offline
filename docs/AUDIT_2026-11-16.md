# Full audit — 16 Nov 2026

Scope: every request the game can send, every libuaf patch, the embedded server code, and a pass through
every screen reachable from the title screen and the adventure map (WSA, debug build with engine logs).
Your save (Aventure 21) was backed up first (`backups/user_20261116e_*`). The audit played no adventure
and spent no gems.

## Bugs found and fixed

| # | Where | Symptom | Cause | Fix |
|---|---|---|---|---|
| 1 | Title screen → **Sauvegardes** | **Game crash** (SIGSEGV) | `userprofile/meta` was not implemented. `{}` → the menu reads 3 save slots from an empty list | Server answers `MetaInfo` with 3 slots (A = your save, B/C empty) |
| 2 | Map → **Classement** | "Échec de la connexion au serveur" every time | Leaderboard requests got a generic answer, and the game treats "no other player" as an error | Real leaderboard answers (`Leaderboards.java`) + libuaf patch `0x169bff8` (skip only that popup) |
| 3 | Title screen → **Actualités** | "Échec de la connexion au serveur" | The news page opens in the game's WebView at `http://rc2.ubi.com/...`, which Android cannot resolve | libuaf patch `0x17ef014` → `http://127.0.0.1:18080/v1/news/<lang>`, server serves a "Pas d'actualité" page |
| 4 | Every date sent by the server | Timers 1 h short in France (incubator end time, mini event) | The game's date parser drops the "+00:00" offset and reads the time as local | Dates are now sent in local time with the offset; old UTC dates are rewritten |
| 5 | Server | Possible corrupted state | The game uses several connections at once; shared state was not locked | Game requests are served one at a time |

## Found after the audit (fresh install)

| 6 | Fresh install, tutorial | "Échec de la connexion au serveur" when dropping the tutorial egg | Fix 0x175b1e0 / 0x17c1188 / 0x17c2a4c forced the server path during the tutorial | Original tutorial logic restored (local during onboarding) |
| 7 | Fresh install, after the tutorial | Same error on every egg; no daily gift | The Ubisoft account could not be created: MobileAuth needs a `Server-Time:` header from `gamecfg-mob.ubi.com/profile/?epoch=1` ("-14 unable get network time"), so the game never logged in | The server sends `Server-Time` on every answer; validated on a fresh install |

## Missing features restored

- **Mini events** ("Mini Marathon", "Skull Scramble"). They were driven by Ubisoft's server, so they never
  appeared offline. They now run every weekend (Friday 00:00 → Monday 00:00), alternating between the two.
  That schedule is our choice; the original calendar is lost. The "PROMO FLASH" popup and countdown were
  checked in game.
- Explicit answers for `storepacks/packs`, `blocksounds`, `adsmanager`, `userprofile/getShortProfiles`,
  `getUserProfile`, `logiap`, `register*`, `stat`, `onBoardingFinished`, `ping`, `leaderboards/postLeaderboard`.
  Before, these got a generic `{"status":200,"result":"ok"}` or the whole store catalogue.

## Checked, no problem

- All 69 request builders in libuaf (functions that build a game-server request) were compared with the server routes (`tools/re/all_requests.py`).
  The rest are either handled, or unreachable offline (real-money packs, `spyGlassPrice` has no caller).
- Legacy patches re-read instruction by instruction:
  - adventure eggs are picked locally (`0x16b2e04`);
  - hatching is local (`0x170aad4`);
  - the internet popup is off;
  - the curl and UbiServices TLS bypasses are in place;
  - the NULL guards are in place.
- About 500 bytes of dead code (the removed item-type guesser) were zeroed. The release lib differs from
  the pre-audit build only by the 4 intended changes.
- Screens checked, no error and no crash:
  - title screen;
  - map;
  - shop (tickets, costumes, élixirs);
  - incubator (empty, elixir counts);
  - missions;
  - mailbox (news / friends / gifts);
  - sacred tree;
  - Classement (Monde / Pays / Amis);
  - Actualités;
  - Sauvegardes;
  - Chaîne Rayman.
- Device config (`deviceconfig`): an empty answer keeps the game's defaults, which are identical to its
  own benchmark config.

## Known limitations (not errors, nothing to fix offline)

- **Real-money purchases** cannot work. Running out of gems opens the paid gem shop ("Échec de la
  connexion"), and "Le must-have pack" does nothing when tapped.
- **Facebook** (title "Connexion", the "Joue avec tes amis" prompt, save sync) cannot work.
- **Chaîne Rayman** (images / comics) is empty: that content was downloaded from Ubisoft and is not in
  the game data.
- **Sauvegardes slots B / C, export, import, delete**: not tested, so as not to touch your save. Only
  slot A (your current save) is known to be correct. Avoid the red delete button.
- Tested on WSA (x86_64 + ARM translation) only, not on a real ARM64 phone.
